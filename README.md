# 5G-reflection-app
A guided reflection tool that helps people reflect on situations and understand the connections between their thoughts, feelings, behavior, and consequences. The application guides users through five steps: 1. Gebeurtenis (event): what happened? 2. Gedachten (thoughts): what thoughts did you have? 3. Gevoelens (feelings): what did you feel? 4. Gedrag (behavior): how did you respond? 5. Gevolg (consequence): what happened as a result? At the end, the app generates a structured summary based on your answers. Project goals: guide users through the five Gs exercise, ask clear questions, let users review and correct their answers, and generate a simple summary. Initial scope: no user accounts, no external AI, no permanent storage yet.
